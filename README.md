# Cidoca Salgados · Calculadora de Preços iFood

Calculadora para definir os preços dos salgados e combos da Cidoca Salgados no iFood (Plano Entrega).

- **Preço de venda:** a partir do valor líquido desejado por salgado, calcula o preço a cadastrar no iFood.
- **Promoções:** sugere o preço sem promoção e o preço "de/por" para anunciar descontos sem perder margem.
- **Tabela de preços:** todos os combos (unitário, 10, 20, 25, 30, 50 e 100), com ou sem refrigerante.

Taxas consideradas: 23% de comissão + 3,2% de pagamento pelo app.

Página única (`index.html`), sem dependências. Publicada via GitHub Pages.
